APEX Export to MD — Panel sterowania

Ścieżki

Ścieżka do katalogu z eksportem APEX (pliki YAML) i/lub plikami DDL (.sql).
Przykład: ./export, C:\projekty\moja_apka\data
Katalog docelowy dla wygenerowanych plików. Zostanie utworzony, jeśli nie istnieje.
Przykład: ./docs, ./output
Prefiks nazw plików wyjściowych. Do nazwy automatycznie dodawany jest timestamp.
Przykład: moja_apka → 20260515_120000_moja_apka_human.md

Format wyjściowy

both — generuje oba formaty Markdown.
human — tylko czytelny Markdown z nagłówkami i tabelami.
llm — skondensowany format liniowy, zoptymalizowany pod AI.
full — dołącza pełny kod PL/SQL i JavaScript.
summary — tylko pierwsza linia kodu z wielokropkiem.
none — pomija wszystkie bloki kodu, zostawia tylko metadane.

Filtrowanie stron

auto — heurystyki: pomija strony administracyjne i systemowe.
all — wszystkie strony bez filtrowania.
prefix:HR_ — tylko strony o nazwach zaczynających się od podanego prefiksu.
ids:2,5,10 — tylko strony o konkretnych ID.
Lista ID stron do dołączenia niezależnie od filtra (rozdzielone przecinkami).
Przykład: 1,100,9999 — dołącza stronę Home i inne pomijane przez filtr.

Opcje eksportu

Zachowuje wewnętrzne identyfikatory APEX (np. 12345678901234.00) w eksporcie. Domyślnie są usuwane jako szum.
Zachowuje informacje o pozycji na stronie, template kolumny i siatce layoutu. Przydatne przy analizie rozkładu regionów.
Dołącza sekcję Shared Components: listy wartości (LOV), schematy autoryzacji, menu nawigacyjne, breadcrumbs, role ACL.
Włącza poziom logowania DEBUG — wyświetla informacje o pomijanych stronach, etapach parsowania i generowania.

Generowanie DDL / Migracja

Generuje wykonywalny skrypt SQL tworzący wszystkie obiekty bazy danych (sekwencje, tabele, widoki, pakiety).
Prefiksy schematu źródłowego są automatycznie usuwane. Kolejność: sekwencje → tabele → widoki → pakiety → klucze obce.
Generuje kompletny skrypt migracyjny: DDL + wyłączenie constraintów + INSERT danych + reset sekwencji + włączenie constraintów.
Wymaga podania connection string do bazy źródłowej. Dane są pobierane w momencie generowania.
Connection string do bazy Oracle. Hasło podaj osobno w polu poniżej.
Przykład: scott@dbserver:1521/ORCL, hr@192.168.1.10:1521/xe
Hasło do konta Oracle. Ze względów bezpieczeństwa nie jest zapisywane w pliku ustawień — trzeba je podać przy każdym uruchomieniu.
